Designing Faculty Onboarding for Canvas at Pitt EDGE

Pitt EDGE builds and maintains online course shells in Canvas through a structured collaboration between faculty, instructional designers, instructional technologists, and quality assurance specialists. This course trains faculty on the full toolkit they'll use to teach online — from secure testing to interactive content to discussion tools.

The work below covers the course's full module sequence: platform orientation, each major third-party tool, and the review workflow that keeps everything accurate before launch.

Module 0

Orienting Faculty and Students to the Platform

Before any tool-specific training starts, faculty and students need a shared baseline: where things live in Canvas, who to contact when something breaks, and which technologies this course actually uses. Module 0 front-loads that orientation so later modules can stay focused on teaching decisions rather than basic navigation.

Module 1

Secure Testing with Respondus

Respondus LockDown Browser and Monitor are often the first unfamiliar tool a faculty member has to configure. This module pairs a low-stakes, unlimited-attempt knowledge check with a summary that explicitly previews what's coming next, so faculty always know where they are in the sequence.

Module 2

Deepening Discussions with Harmonize

Harmonize layers richer discussion features on top of Canvas's native tool. Rather than just listing features, this module argues for the tool by contrasting it directly against what faculty already know, then hands them the setup mechanics once they're convinced it's worth the switch.

Module 3

Building Assessments in ExamSoft

ExamSoft is the most operationally dense tool in the course, so this module is built around a single visual anchor — Set Up → Build → Deliver — that recurs on every page. Each page answers one decision faculty actually have to make, like Blueprint vs. standalone, rather than documenting every field in the interface.

Module 4

Closing the Loop with BugHerd

Once a course is built, faculty need a way to flag problems without writing a formal bug report. This module documents BugHerd, which turns point-and-click feedback on the live course into tracked tasks for the instructional designer — explaining that handoff to both sides of it.

Module 5

Running Live Sessions in Zoom

Zoom's documentation needed to cover two different audiences at once: faculty running the session and students joining it. This module interleaves instructor-facing setup with a dedicated student troubleshooting guide, and uses flip-cards to keep dense settings information from overwhelming the page.

Module 6

Visual Collaboration with Lucid

Lucid's two products — Lucidchart for diagrams, Lucidspark for whiteboards — get taught through contrast. The module embeds one editable board and one view-only board side by side, so faculty directly experience the permission difference instead of just reading about it.

Module 8

Supporting Self-Study with Osmosis

Osmosis isn't integrated with Canvas, so every example in this module has to bridge two systems: instructions live in Canvas, the actual work happens in Osmosis, and a reflection brings the student back. The module also draws a clear line between flashcards (recall) and questions (application) so faculty choose the right tool for their learning goal.

Module 9

Building Interactive Content with H5P

H5P is the most content-creation-heavy tool in the course, so this module is organized around a Set Up / Deliver / Wrap Up arc and includes real, working examples — not just screenshots of the editor. The hotspot activity below is shown at two different attempt counts specifically to demonstrate the immediate-feedback loop in action.

Module 10

Grounding Learning in Patient Cases with ReelDx

ReelDx's library of authentic patient videos is the kind of resource that's easy to drown faculty in. This module leads with an interactive platform tour, then narrows immediately to the two decisions that matter most: how to filter a 700-case library, and how to turn a case into a graded Canvas assignment.
